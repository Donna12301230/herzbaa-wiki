# 赫滋與羊 HerzBaa｜LLM Wiki

依 [Karpathy 的 LLM Wiki](https://gist.github.com/karpathy/442a6bf555914893e9891c11519de94f) 構想建立的品牌知識庫：
`raw/` 放公開的原始來源（官網、IG、作品集），`wiki/` 是 AI 整理維護的知識頁，規則都寫在 [AGENTS.md](AGENTS.md)。

- 需求怎麼來的：[docs/需求訪談紀錄.md](docs/需求訪談紀錄.md)（先討論、後生成）
- 從哪裡開始讀：[wiki/index.md](wiki/index.md)
- 健檢：`python tools/lint.py`

可以用 Obsidian 開啟 `wiki/` 資料夾，看頁面之間的關聯圖。
