## 需求摘要（使用者已確認）

| # | 項目 | 決定 |
|---|---|---|
| 1 | 主題 | 赫滋與羊 品牌 IP |
| 2 | 讀者 | Wiki 主要給 AI 讀；簡報給新合作夥伴／店家，看完知道「這個品牌是誰、可以怎麼合作」 |
| 3 | raw 來源 | 官網 herzbaa.com 文章、IG @ckhz.art 貼文、作品集＋故事模特 PDF（至少 5 篇）；不放合約、稅務、個資、繪本全文 |
| 4 | 頁面類型 | 實體頁、來源摘要頁、合作問答頁、品牌時間線、index.md、log.md |
| 5 | 來源矛盾 | 兩說並列附出處、標【待確認】、記進 log，等使用者拍板；簡報不引用待確認內容；「赫茲」一律是錯字 |
| 6 | Ingest | 一次一篇、互動：先回報重點與要改的頁，使用者 OK 才寫入 |
| 7 | Lint | 出處與連結、品牌用字、個資與未公開資訊、待確認與孤兒頁；能程式化的寫成 tools/lint.py |
| 8 | 簡報 | 品牌風配色＋公開過的角色圖，10–14 頁，鍵盤翻頁 |
| 9 | 流程 | Graph：查 Wiki → 覆蓋率關卡 → 大綱 →【人工確認大綱】→ 逐頁稿 → 忠實度檢查 → 渲染 HTML → 版面檢查 → 交件＋檢查報告 |
| 10 | 特殊規則 | ① 作品寓意只引用創作者原文，AI 不詮釋，沒原文標【待補】 ② 每頁一句話摘要＋關鍵字，供赫滋小編與官網機器人共用 ③ 只收公開資訊，合作條件與報價寫「請洽創作者」 ④ 每發新文章就 ingest，log 記錄更新了哪些頁 |

## 和 Karpathy 原版不同的地方（作業反思用）

| Karpathy 原版 | 這份 Wiki 的調整 | 為什麼 |
|---|---|---|
| 個人研究筆記，內容私有 | 只收公開資訊、lint 會掃個資與金額 | repo 要公開在 GitHub，而品牌資料夾裡混有合約與個資 |
| LLM 可以自由整理、綜合 | 作品寓意只能引用原文，不准 AI 詮釋 | 作品的意義是創作者的創作，AI 美化或猜測會傷害品牌 |
| 矛盾時由 LLM 標註 | 兩說並列＋【待確認】＋對外成品禁用 | 品牌說法要由創作者本人拍板 |
| 一份 wiki 服務一個人 | 每頁 summary＋keywords，多個 agent 共用 | 之後赫滋小編、官網機器人都要讀同一份 |
